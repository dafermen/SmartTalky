# Glosario bilingüe técnico

| Español | Inglés / identificador sugerido | Definición |
|---|---|---|
| Pronunciación | pronunciation | Realización sonora de una palabra o frase. |
| Variante regional | locale | Convención regional; inicialmente `en-US`. |
| Sílaba tónica | stressed syllable | Sílaba con mayor prominencia en una palabra. |
| Alfabeto Fonético Internacional | IPA | Sistema estándar de símbolos fonéticos. |
| División silábica | syllabification | Separación educativa de una palabra en sílabas. |
| Modo natural | natural mode | Pronunciación a ritmo conversacional previsto. |
| Modo lento | slow mode | Pronunciación más pausada para distinguir partes. |
| Modo profesor | teacher mode | Secuencia pedagógica natural–lenta/segmentada–natural. |
| Síntesis de voz | text-to-speech / TTS | Conversión de texto en audio hablado. |
| Proveedor TTS | `TextToSpeechProvider` | Interfaz que desacopla el caso de uso del servicio externo. |
| Caché | cache | Almacenamiento que permite reutilizar audio compatible. |
| Acierto de caché | cache hit | Solicitud satisfecha con un audio ya válido. |
| Fallo de caché | cache miss | Ausencia de audio compatible que requiere generación. |
| Clave de caché | cache key | Hash determinista de la identidad completa del audio. |
| Normalización | normalization | Limpieza controlada que no cambia el significado. |
| Deduplicación concurrente | request coalescing | Unión de solicitudes simultáneas equivalentes en un solo trabajo. |
| Escritura atómica | atomic publication | Publicación completa que evita exponer archivos parciales. |
| Contrato | contract | Esquema compartido de entradas, salidas y errores. |
| Caso de uso | use case | Coordinación de una acción del negocio independiente de HTTP. |
| Adaptador | adapter | Implementación que conecta una interfaz con infraestructura. |
| Almacenamiento local | local storage | Persistencia en el dispositivo/navegador del usuario. |
| Internacionalización | internationalization / i18n | Preparación de software para varios idiomas y regiones. |
| Idioma de interfaz | interface language | Idioma de botones, mensajes y navegación. |
| Idioma nativo | native language | Idioma principal del estudiante. |
| Idioma de aprendizaje | learning language | Idioma que el estudiante practica. |
| ADR | Architecture Decision Record | Registro versionado de una decisión arquitectónica importante. |
